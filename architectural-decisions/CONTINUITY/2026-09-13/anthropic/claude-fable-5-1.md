## 2. STT design — the settled decisions (do not re-litigate)

- **Four nodes:** `aic-client ⇄ aic-server ⇄ xai-client ⇄ xai-server`. Hop 1 is **all typed JSON events** (audio = base64 event); hop 2 is raw binary. The `isBinary` gate / `{raw,isBinary}` inbox design is withdrawn.
- **Naming:** socket field is `ws` everywhere (`STTSession.ws`); provider socket is `xaiClient` (never "upstream"); `openXaiClient`, `MAX_XAI_CLIENT_BUFFER`.
- **Config is app-owned:** `encoding=pcm`, `sample_rate` = actual capture-graph rate (validated; quality across rates **unmeasured**, 16 kHz is the documented native rate, cost is per-minute so rate isn't a cost decision), `interim_results=false` — **finalized `transcript.partial` events still arrive** (`is_final=true` chunk-finals ~3 s / utterance-finals) and are the checkpoints; "partial" is xAI's confusing wire name for every non-done result. `endpointing` default, never a capture stop. `language` from the locale cookie via `useLangSTT` (`languageHelperSTT`: first subtag, lowercase, anchored `^[a-z]{2,3}$`, `tl → fil`), only formatting, banner says "formatting unavailable, dictation still works". Omit smart_turn/diarize/multichannel/vad; keyterms later.
- **No silence/duration cutoff.** Idle = **prompted**: server sees 30 s with no finalized utterance → `stt_user_timeout {closesInMs: 15000}` → dialog; `stt_user_present` (button **or** local `AnalyserNode` voice-energy) resets; lapse → server sends `audio.done`, `IDLE_TIMEOUT`, `stt_user_finished` exactly like ■. Server-authoritative; client sends nothing on lapse.
- **UI:** ChatGPT-style waveform bar; ✕ / ■ / ↑. ✕ is **two-phase**: finish like ■ (text arrives via `stt_user_finished`), undo toast client-side, lapse → `stt_user_cancel` → row `CANCELED/RECOVERABLE (+1 h)` or `CANCELED/ORPHANED` tombstone if nothing to keep. ↑ = client auto-`sendChat` on `finished`. Stop/Send disabled until `connected`; ✕ always. **No `finalize` on cancel** — `audio.done` yields the authoritative stitched `transcript.done`.
- **Row lifecycle:** insert at `stt_user_connect` **before** `xaiClient` opens (like the user message before provider work); `transcript.created` → `externalId`, GENERATING; `transcript.done` → content, COMPLETED, DECOUPLED. Coupling = `updateMany where {batchId, userId, couplingStatus: "DECOUPLED"} → {messageId, conversationId, messageOrdinal, COUPLED}` at the `resolver/chat.ts` convergence point after `handleAiChatRequest` (outside the 16-branch matrix); request carries `sttBatchId?` (Andrew's contract, not yet added to `AIChatRequest`). Termination mapping: USER_FINISHED/IDLE_TIMEOUT → COMPLETED/DECOUPLED; USER_CANCELED → CANCELED/RECOVERABLE; CLIENT_DISCONNECTED → INTERRUPTED/RECOVERABLE; UPSTREAM/INTERNAL with text → INTERRUPTED/RECOVERABLE, without → FAILED/FAILED.
- **Expiry:** `DECOUPLED` (kept drafts) **never expire** — Andrew has left drafts+attachments in a tab 12 h and sent fine. `RECOVERABLE` (cancelled/lost text) = 1 h then tombstone (`ORPHANED`, `content = ""`). Sweep `where {couplingStatus: RECOVERABLE, recoveryExpiresAt < now}` can't touch DECOUPLED by construction. **New-chat is not special-cased anywhere** (cuid2 batchIds removed the collision).
- **Navigation never cancels:** socket alive → implicit `stt_user_finish`, DECOUPLED, bound to the originating draft (hydrate back via `{userId, conversationId|null, couplingStatus: DECOUPLED}`); socket dead → server close handler bounded completion → INTERRUPTED/RECOVERABLE/CLIENT_DISCONNECTED; surfaced later via `stt_user_recover` (no draftIds — server query) → `stt_user_restore` (→ DECOUPLED, expiry nulled). `stt_user_interrupted` = session died with the client present (UPSTREAM/INTERNAL only); lands RECOVERABLE so the user decides.
- **Redis = in-flight only:** `stt:{userId}:{draftId}` checkpoints via a **single-slot coalescing writer + synchronous terminal gate** (not a promise chain), storage deadline (`RedisInstance` has `disableOfflineQueue: false` → commands stall on reconnect; use command timeout, never change the shared policy), ownership `SET stt:own:{userId}:{draftId} NX EX lease` renewed with silence; released at DECOUPLED/FAILED.
- **Ordering:** the frame handler forwards **synchronously** (no `await` before `xaiClient.send`); `frameOrdinal` is a gap (interrupt) / duplicate (drop) detector; frames with a mismatched `draftId` are stale tails → dropped.
- **Client `sendImmediate`** (typed sibling of `send`, never queued/replayed); `bufferedAmount` ceilings both hops; worklet flush ack before `finish`; explicit float→Int16LE→base64.
- **Provenance/comparison** (M3/M4): raw text per row cascades with the message, never enters prompts/logs; comparison is evidence-about-edits, off-thread, bounded, nullable. Raw audio **never** persisted.
